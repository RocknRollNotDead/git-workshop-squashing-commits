# Воркшоп по git - squash коммитов

Контекст - иногда в процессе работы над проектом мы коммитим неполные или слишком мелкие изменения, и возникает необходимость объединить несколько коммитов в один.

Задачи:

1. Объединить коммиты `18433953` и `7fc78bfb`
2. Объединить 2 последних коммита в один

## Как пользоваться

- Сделайте fork данного репозитория
- Склонируйте локально
- Решите локально
- Сравните локальную и удалённую ветку main, разницы в файлах быть не должно
